# Content Studio — Product Brief

## Problem
Creators and entrepreneurs need quality content across many topics, formats, and media, but drafting takes too long and lacks a structure that drives real transformation in the reader's life.

## Target user
Solo content creators and early-stage entrepreneurs who publish to grow an audience and drive action — not large teams, not agencies.

## Core objects
- **Content piece** — one publishable unit: topic, format (post/carousel/script), media type (text/image/video), audience, breakthrough angle, hook, body, CTA, status.
- **Topic** — a content category the creator writes in (e.g. Personal Growth, Business & Money).
- **Activity** — a logged action on a piece (create, edit, publish, score).
- **Audit log** — who did what, to what, when.

## MVP (v1) — must haves
- [ ] Create a content piece: pick topic + format + media + audience, write breakthrough angle, hook, body, CTA.
- [ ] Save as draft; mark published.
- [ ] Content library: list, filter by status/topic, edit, delete.
- [ ] AI assist to draft hook/body/CTA from the breakthrough angle (optional, reviewable, AI-off fallback).
- [ ] Works without login (demo seed data visible).
- [ ] Loading / empty / error states on every screen.

## Non-goals (v1)
- User accounts and login.
- Publishing to social platforms.
- Team collaboration.
- Analytics/imported metrics.

## Success criteria (concrete)
A user opens the app, creates a new content piece on "Personal Growth", selects format=post, writes a breakthrough angle, drafts hook+body+CTA (with optional AI help), saves, sees it appear in the library marked published — all within 15 minutes, no login required, data persisted to the database.
